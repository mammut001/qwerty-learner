# Qwerty Français — TCF Canada

一个只保留法语内容的 Qwerty Learner fork，用打字练习记忆 TCF Canada 高频词汇与表达。

## 当前词库

- TCF Canada 基础核心词 01：102
- TCF Canada 日常生活：80
- TCF Canada 工作·学习·行政：76
- TCF Canada B1 连接词：64
- TCF Canada B2 观点表达：72
- TCF Canada 口语·写作表达：64

当前共 458 个学习项，后续继续扩充。

## 特点

- 只展示法语词库，不保留原版英语、日语、德语等词库。
- 默认语言与词库均为法语 / TCF Canada。
- 支持法语重音字符输入。
- 支持法语单词朗读。
- 保留章节练习、错题复习、默写、速度与正确率统计等原版核心功能。

## 本地运行

```bash
yarn
yarn start
```

默认开发地址为 `http://localhost:5173/`。

## 部署

仓库已保留 GitHub Pages workflow，推送到 `master` 后可构建并发布到 `gh-pages`。
